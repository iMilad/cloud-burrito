Settings

Display preferences

Display preferences apply immediately and are saved on this device.

AWS

Preserve keeps existing history without automatic expiry. Bounded retention uses up to five files of 10 MiB each (50 MiB total); the oldest file expires on rotation. This choice takes effect only when you save. Preserved copies never expire automatically and are outside that budget.

Blank fields use the defaults shown. Color-theme changes are previews until you save.

Use a profile configured for IAM Identity Center (SSO). Complete your existing SSO login outside this app, then retry the connection. The app uses your existing SSO session to obtain temporary AWS credentials; it does not start an interactive login.

The app checks requested operations against its supported list and your policy before execution. Logs Insights requires permission to both start and stop queries; queries can incur AWS charges. Blocked calls show up in the Audit log panel.

Operation policy

IAM-style allowlist. Explicit Deny > Allow > default-deny; globs * and ? work. It can only narrow what the app calls — it cannot enable unsupported operations.
