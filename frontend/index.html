Settings

      
    

    

      

        
AWS

        

          
          
          
          
          

            Read-only enforcement is unconditional: every AWS service call is
            checked against the structural read-only guard and your policy below
            before it runs, including identity checks and the pipeline picker.
            Blocked calls show up in the Audit log panel.
          

          

          

            
            
          

        

      

      

        
Read-only policy

        

          IAM-style allowlist. Explicit Deny > Allow > default-deny; globs
          * and ? work. It can only narrow what the app
          calls — it can never enable a write.
        

        

        

        

          

          
        

        

          
          
        

      

    

  


  
  

    

      
Audit log

      
    

    

      

        Last 300 entries, newest first. Auto-refreshes every 2 seconds while
        open. Captures lifecycle events, set-account attempts, every AWS service
        call the Rust core makes, and any call blocked by the read-only guard or
        policy. Request params aren't recorded; AWS calls log only service +
        operation + account + region.
        On disk: ~/.cloud_burrito/audit.log.
      

      

    

  


  
  

    

      
Identity

      
    

    

      

        Live state of the active AWS context: which profile, which role you
        asked for, which role SSO actually gave you, and whether the assumed
        identity is still valid.
