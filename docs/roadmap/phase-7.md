# P7 — Build the portfolio launch package

**Planned; not started.** This was the original P6 before the creative interface phase was inserted on 2026-09-04. The purpose is to make the product, engineering decisions and evidence understandable to a prospective user or reviewer. Pricing and commercial sales are outside this phase.

## Ordered work

| Unit | Work | Exit condition |
| --- | --- | --- |
| P7-01 — Explain the product | Prepare a concise English overview: who it serves, the investigation problem, the connected workflow and current limits | A reader can understand the value and intended use without reading source code; supported-platform claims match P6 evidence |
| P7-02 — Show the experience | Prepare a short synthetic demonstration, selected screenshots and a small architecture/decision explanation | Show the actual reviewed interface and a complete investigation; identify simulated data and distinguish personal contribution, AI assistance and inherited work accurately |
| P7-03 — Prepare the public repository | Review installation guidance, troubleshooting, contribution instructions, license/dependency disclosures and privacy/history evidence | The local repository package is concrete and reviewable; fresh relevant checks and unresolved limitations are recorded |
| P7-04 — Make the publication decision | Present the exact source, candidate files, device results, public materials and any remaining risks | The owner can approve a clearly identified publication action; approval and execution remain separate from documentation readiness |

## Evidence standard

Use the final P5 interface and the exact candidate accepted in P6. Link measured performance to its environment and method. Keep source/build checks distinct from native install/launch evidence; missing devices or blocked connected journeys remain explicit limitations. Do not imply universal Linux compatibility, verified AWS behavior or unsigned-package publisher authentication without the corresponding evidence.

Keep screenshots, examples and demonstrations synthetic. No credential contents, real AWS identifiers, personal filesystem paths or private investigation data belong in the public package. Explain what was designed, implemented and validated in concrete terms rather than inflated ownership or speed claims.

## Exit and next step

The deliverable is a complete local English portfolio package and a recommendation supported by the recorded candidate/device evidence. It creates no automatic permission to push, tag, start a GitHub workflow, draft a release or publish publicly. Follow the repository release rules and the owner's explicit instruction when a later publication action is approved.
