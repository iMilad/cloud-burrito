# Watchlist and Command Line Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the default-account dashboard with a keyboard-first watchlist
of specific things from many AWS accounts, an inspector that drills down step
by step, and a vim-style command line. Every current capability stays and no
AWS operation is added.

**Architecture:**
- The backend gets two small read-only additions:
  - `watchlist.json` storage with `watchlist_get` / `watchlist_set`
  - an optional pinned `context` on `aws_auth_status`
- The frontend's security-sensitive shared code (request ownership, result
  states, renderers) moves unchanged from `app.js` into `core.js`, behind a
  small hook interface. The old page and the new page both use it.
- The new UI is built in small plain-script files:
  - at `watchlist.html` during steps 1–3, beside the untouched old `index.html`
  - in step 4 it replaces `index.html`, and the old UI is deleted

**Tech Stack:**
- Rust 1.91.1 with Tauri 2 (`src-tauri/`)
- Vanilla JS with no build step (`frontend/`)
- `node --test` for unit tests (`tests/unit/`)
- Playwright 1.61.1 browser tests against Chromium (`tests/frontend/`)
- Python 3 release-helper tests (`tests/scripts/`)

**Spec:** `docs/superpowers/specs/2026-11-02-watchlist-redesign-design.md` (read it first; this plan argues from it)

## Global Constraints

- Branch: `mk/watchlist-redesign`. Commit after every task. Never push or tag
  without the user's explicit OK. Releases are paused.
- **No new AWS operations.** Do not change `src-tauri/src/aws/guard.rs`
  (`APP_OPS`), `aws/policy.rs` gates, the CLI argument schemas in
  `widgets/aws_cli.rs`, or the scheduler limits (8 total / 4 per service /
  queue 128).
- Every thing carries `context: {mode: "pinned", profile, account_id, region}`.
  There is no inherited account in the new UI.
- **Load when the user looks.** No timers that call AWS. `query`, `errors` and
  `cli` things never run on their own, only on `r`.
- No per-account health or "needs attention" badges.
- Frontend files stay plain scripts (no `type="module"`), so `file://` demo
  pages keep working.
- **Copy rules:**
  - sentence case
  - say what happened and what to do
  - no "please", "successfully" or exclamation marks
  - no ALL CAPS labels
- **Tests and CI never call live AWS** and never read real credentials.
  Synthetic names only: `demo-*`, `acct-*-fixture`, `synthetic-*`, `acme-*`.
- Gates that must stay green after every task:
  - `npm run test:unit`
  - `npx playwright test` (needs a local port; run outside the sandbox if
    binding fails)
  - `cd src-tauri && cargo fmt --all --check && cargo test -p cloud-burrito --locked && cargo clippy -p cloud-burrito --locked -- -D warnings`
  - `python3 scripts/check-tauri-commands.py`
  - `python3 scripts/check-release-privacy.py`
  - `python3 -m unittest discover -s tests/scripts -p 'test_*.py'`
  - `git diff --check`
- Allowed regions stay `eu-west-1` and `us-east-1` (`settings::ALLOWED_REGIONS`).
- Thing limit: 200 (validated in Rust).

```rust
use serde_json::{json, Value};

use crate::storage::{self, StorageError, Store};

pub(crate) const FILE: &str = "watchlist.json";

pub(crate) fn load(store: &Store) -> Result<Value, StorageError> {
    let Some(data) = store.read_json(FILE)? else {
        return Ok(storage::status(
            json!({"version": 1, "things": []}),
            "watchlist",
            "missing",
        ));
    };
    if !data.is_object() || data.get("version") != Some(&json!(1)) {
        return Err(StorageError::Invalid);
    }
    let things = data.get("things").ok_or(StorageError::Invalid)?;
    crate::validation::validate("watchlist_set", &json!({"things": things}))
        .map_err(|_| StorageError::Invalid)?;
    Ok(storage::status(
        json!({"version": 1, "things": things}),
        "watchlist",
        "loaded",
    ))
}

pub(crate) fn save(store: &Store, things: &Value) -> Result<Value, StorageError> {
    crate::validation::validate("watchlist_set", &json!({"things": things}))
        .map_err(|_| StorageError::Invalid)?;
    let out = json!({"version": 1, "things": things});
    store.write_json(FILE, &out)?;
    Ok(storage::status(out, "watchlist", "saved"))
}
```

```rust
#[tauri::command]
pub async fn watchlist_get(state: State<'_, AppState>) -> Result<Value, String> {
    final_diagnostics(&state, Ok(watchlist_get_impl(&state))).await
}

fn watchlist_get_impl(state: &AppState) -> Value {
    state.runtime.with_diagnostics(
        crate::watchlist::load(&state.runtime.storage)
            .unwrap_or_else(|error| error.response("watchlist")),
    )
}

#[tauri::command]
pub async fn watchlist_set(state: State<'_, AppState>, params: Value) -> Result<Value, String> {
    final_diagnostics(&state, Ok(watchlist_set_impl(&state, params))).await
}

fn watchlist_set_impl(state: &AppState, params: Value) -> Value {
    if let Some(error) = local_validation(state, "watchlist_set", &params) {
        return error;
    }
    state.runtime.with_diagnostics(
        crate::watchlist::save(&state.runtime.storage, &params["things"])
            .unwrap_or_else(|error| error.response("watchlist")),
    )
}
```

**Interfaces:**
- Produces `window.CloudBurritoThings` (works the same in node `vm`):
  - `GROUPS`: `[{key, label}]` in display order
  - `KINDS[kind]`: `{group, badge, autoload, title, cost?}`
  - `inputsFor(kind, raw)` → normalized inputs, or `null` if invalid
  - `normalize(raw)` → `{id, kind, context, inputs, order}`, or `null`
  - `create(kind, context, inputs, existingThings)` → a new thing (unique `id`, `order` = last in its group + 1), or `null`
  - `name(thing)` → string
  - `rowRequest(thing)` → `{widget, inputs}`
  - `summarize(thing, result)` → `{tone, text, at}`. `tone` is one of `"ok" | "fail" | "run" | "warn" | "muted"`; `at` is epoch ms or `null`
  - `statusTone(status)` → tone
  - `groupThings(things)` → `[{key, label, things}]` (non-empty groups, sorted by `order`)
  - `move(things, id, delta)` → new array
  - `toStored(things)` → array of storable things

```js
// No DOM, bridge or AWS. Loaded as a plain script and by node unit tests.
(function (root) {
  "use strict";

  const GROUPS = [
    { key: "pipelines", label: "Pipelines" },
    { key: "packages", label: "Packages" },
    { key: "logs", label: "Logs" },
    { key: "stacks", label: "Stacks" },
    { key: "saved", label: "Saved commands" },
  ];
  const KINDS = {
    pipeline: { group: "pipelines", badge: "P", autoload: true, title: "Pipeline" },
    package: { group: "packages", badge: "A", autoload: true, title: "Package" },
    logs: { group: "logs", badge: "L", autoload: true, title: "Logs" },
    stack: { group: "stacks", badge: "S", autoload: true, title: "Stack" },
    "stacks-search": { group: "saved", badge: "S", autoload: true, title: "Stacks search" },
    lookup: { group: "saved", badge: "R", autoload: true, title: "Resource lookup" },
    query: { group: "saved", badge: "Q", autoload: false, title: "Logs Insights query", cost: true },
    errors: { group: "saved", badge: "E", autoload: false, title: "Error counts", cost: true },
    cli: { group: "saved", badge: "C", autoload: false, title: "AWS CLI command" },
  };
  const CONTROL = /[\u0000-\u001f\u007f]/u;

  function text(value, max = 2048) {
    if (typeof value !== "string") return "";
    const trimmed = value.trim();
    return trimmed && trimmed.length <= max && !CONTROL.test(trimmed) ? trimmed : "";
  }
  function multiline(value, max) {
    if (typeof value !== "string") return "";
    const trimmed = value.trim();
    return trimmed && trimmed.length <= max && !/[\u0000-\u0008\u000b\u000c\u000e-\u001f\u007f]/u.test(trimmed) ? trimmed : "";
  }
  function int(value, min, max, fallback) {
    const number = typeof value === "string" ? Number.parseInt(value, 10) : value;
    return Number.isSafeInteger(number) && number >= min && number <= max ? number : fallback;
  }

  function pinned(raw) {
    if (!raw || typeof raw !== "object" || raw.mode !== "pinned") return null;
    const profile = text(raw.profile, 256), account = text(raw.account_id, 128), region = text(raw.region, 128);
    return profile && account && region ? { mode: "pinned", profile, account_id: account, region } : null;
  }

  function inputsFor(kind, raw) {
    const r = raw && typeof raw === "object" && !Array.isArray(raw) ? raw : {};
    switch (kind) {
      case "pipeline": { const name = text(r.pipeline_name); return name ? { pipeline_name: name } : null; }
      case "package": {
        const domain = text(r.domain), repository = text(r.repository), prefix = text(r.package_prefix);
        if (!domain || !repository || !prefix) return null;
        const owner = typeof r.domain_owner === "string" ? r.domain_owner.trim() : "";
        if (owner && !/^\d{12}$/.test(owner)) return null;
        return { domain, repository, package_prefix: prefix, ...(owner ? { domain_owner: owner } : {}) };
      }
      case "logs": {
        const group = text(r.log_group);
        if (!group) return null;
        const source = r.source === "lambda" ? "lambda" : "group";
        const fn = source === "lambda" ? text(r.function_name, 256) : "";
        return { log_group: group, source, ...(fn ? { function_name: fn } : {}) };
      }
      case "stack": { const name = text(r.stack_name); return name ? { stack_name: name } : null; }
      case "stacks-search": {
        const prefix = typeof r.name_prefix === "string" && !CONTROL.test(r.name_prefix) ? r.name_prefix.trim().slice(0, 2048) : "";
        const filter = Array.isArray(r.status_filter) ? r.status_filter.map(s => text(s, 128)).filter(Boolean).slice(0, 64) : [];
        return { name_prefix: prefix, ...(filter.length ? { status_filter: filter } : {}) };
      }
      case "lookup": { const query = text(r.query); return query ? { query } : null; }
      case "query": {
        const group = text(r.log_group), query = multiline(r.query, 10240);
        return group && query ? { log_group: group, query, range_seconds: int(r.range_seconds, 60, 604800, 3600) } : null;
      }
      case "errors": {
        const pattern = typeof r.log_group_pattern === "string" && !CONTROL.test(r.log_group_pattern)
          ? r.log_group_pattern.trim().slice(0, 2048) : "/aws/lambda/";
        return { hours: int(r.hours, 1, 168, 24), log_group_pattern: pattern || "/aws/lambda/" };
      }
      case "cli": {
        const command = text(r.command, 16384);
        return /^aws\s+\S/.test(command) ? { command } : null;
      }
      default: return null;
    }
  }

  function normalize(raw) {
    if (!raw || typeof raw !== "object") return null;
    const id = text(raw.id, 256);
    const kind = Object.hasOwn(KINDS, raw.kind) ? raw.kind : null;
    const context = pinned(raw.context);
    const inputs = kind ? inputsFor(kind, raw.inputs) : null;
    if (!id || !kind || !context || !inputs) return null;
    return { id, kind, context, inputs, order: int(raw.order, 0, 100000, 0) };
  }

  function create(kind, context, inputs, existing = []) {
    const order = existing.filter(t => t.kind === kind).reduce((max, t) => Math.max(max, t.order), -1) + 1;
    const random = Math.random().toString(36).slice(2, 8);
    return normalize({ id: `${kind}-${Date.now().toString(36)}-${random}`, kind, context, inputs, order });
  }

  function name(thing) {
    const i = thing.inputs;
    switch (thing.kind) {
      case "pipeline": return i.pipeline_name;
      case "package": return i.package_prefix;
      case "logs": return i.function_name || i.log_group;
      case "stack": return i.stack_name;
      case "stacks-search": return i.name_prefix ? `stacks ${i.name_prefix}` : "all stacks";
      case "lookup": return `lookup ${i.query}`;
      case "query": return `insights ${i.log_group}`;
      case "errors": return `errors ${i.log_group_pattern}`;
      case "cli": return i.command;
      default: return thing.id;
    }
  }

  function rowRequest(thing) {
    const i = thing.inputs;
    switch (thing.kind) {
      case "pipeline": return { widget: "pipeline-runs", inputs: { pipeline_name: i.pipeline_name, max_results: 5 } };
      case "package": return { widget: "codeartifact-packages", inputs: { mode: "list", domain: i.domain, repository: i.repository,
        package_prefix: i.package_prefix, max_packages: 5, ...(i.domain_owner ? { domain_owner: i.domain_owner } : {}) } };
      case "logs": return { widget: i.source === "lambda" ? "log-tail" : "cloudwatch-logs",
        inputs: { mode: "streams", log_group: i.log_group, max_streams: 1 } };
      case "stack": return { widget: "cfn-stack-detail", inputs: { stack_name: i.stack_name } };
      case "stacks-search": return { widget: "cfn-stacks", inputs: { name_prefix: i.name_prefix,
        ...(i.status_filter ? { status_filter: i.status_filter } : {}) } };
      case "lookup": return { widget: "resource-lookup", inputs: { query: i.query, max_results: 25 } };
      case "query": return { widget: "logs-insights", inputs: { mode: "query", log_group: i.log_group, query: i.query, range_seconds: i.range_seconds } };
      case "errors": return { widget: "errors-by-stack", inputs: { hours: i.hours, log_group_pattern: i.log_group_pattern } };
      case "cli": return { widget: "aws-cli", inputs: { command: i.command } };
      default: throw new Error("Unknown thing kind");
    }
  }

  function words(status) {
    const raw = String(status || "").replace(/([a-z0-9])([A-Z])/g, "$1 $2").replace(/[_-]+/g, " ").trim().toLowerCase();
    return raw ? raw.charAt(0).toUpperCase() + raw.slice(1) : "";
  }
  function statusTone(status) {
    const s = String(status || "").replace(/([a-z0-9])([A-Z])/g, "$1_$2").toUpperCase();
    if (s.includes("FAILED") || s.includes("ROLLBACK")) return "fail";
    if (s.includes("IN_PROGRESS") || s.includes("STOPPING") || s === "IN_PROGRESS") return "run";
    if (s.includes("COMPLETE") || s.includes("SUCCEEDED")) return "ok";
    return "muted";
  }
  const time = value => { const t = Date.parse(value); return Number.isFinite(t) ? t : null; };

  function summarize(thing, result) {
    const rows = Array.isArray(result?.rows) ? result.rows : [];
    switch (thing.kind) {
      case "pipeline": {
        if (!rows.length) return { tone: "muted", text: "No runs", at: null };
        return { tone: statusTone(rows[0].status), text: words(rows[0].status), at: time(rows[0].last_updated) };
      }
      case "package": {
        const exact = rows.find(r => r.package === thing.inputs.package_prefix);
        if (exact?.latest_version) return { tone: "muted", text: String(exact.latest_version), at: time(exact.last_published) };
        return { tone: "muted", text: `${rows.length} package${rows.length === 1 ? "" : "s"}`, at: null };
      }
      case "logs": {
        const stream = Array.isArray(result?.streams) ? result.streams[0] : null;
        return stream ? { tone: "muted", text: "last event", at: Number(stream.last_event_timestamp) || null }
          : { tone: "muted", text: "No streams", at: null };
      }
      case "stack": {
        const events = Array.isArray(result?.events) ? result.events : [];
        const own = events.find(e => e.logical_id === thing.inputs.stack_name);
        if (own) return { tone: statusTone(own.status), text: words(own.status), at: time(own.time) };
        const count = Array.isArray(result?.resources) ? result.resources.length : 0;
        return { tone: "muted", text: `${count} resource${count === 1 ? "" : "s"}`, at: null };
      }
      case "stacks-search": return { tone: "muted", text: `${rows.length} stack${rows.length === 1 ? "" : "s"}`, at: null };
      case "lookup": {
        const n = Array.isArray(result?.matches) ? result.matches.length : 0;
        return { tone: "muted", text: `${n} match${n === 1 ? "" : "es"}`, at: null };
      }
      case "errors": {
        if (!rows.length) return { tone: "muted", text: "No errors returned", at: null };
        const top = rows.reduce((a, b) => (Number(b.errors) || 0) > (Number(a.errors) || 0) ? b : a);
        return { tone: "fail", text: `${top.stack}: ${Number(top.errors) || 0}`, at: null };
      }
      default: return { tone: "muted", text: `${rows.length} row${rows.length === 1 ? "" : "s"}`, at: null };
    }
  }

  function groupThings(things) {
    return GROUPS.map(group => ({ ...group, things: things.filter(t => KINDS[t.kind].group === group.key)
      .slice().sort((a, b) => a.order - b.order || a.id.localeCompare(b.id)) }))
      .filter(group => group.things.length);
  }

  function move(things, id, delta) {
    const target = things.find(t => t.id === id);
    if (!target) return things;
    const peers = things.filter(t => KINDS[t.kind].group === KINDS[target.kind].group)
      .slice().sort((a, b) => a.order - b.order || a.id.localeCompare(b.id));
    const index = peers.indexOf(target), next = index + delta;
    if (next < 0 || next >= peers.length) return things;
    [peers[index], peers[next]] = [peers[next], peers[index]];
    const orders = new Map(peers.map((t, n) => [t.id, n]));
    return things.map(t => orders.has(t.id) ? { ...t, order: orders.get(t.id) } : t);
  }

  function toStored(things) {
    return things.map(t => ({ id: t.id, kind: t.kind, context: { ...t.context }, inputs: { ...t.inputs }, order: t.order }));
  }

  root.CloudBurritoThings = { GROUPS, KINDS, inputsFor, normalize, create, name, rowRequest, summarize, statusTone,
    groupThings, move, toStored, words };
})(typeof window !== "undefined" ? window : globalThis);
```

```js
// Pure key map for the watchlist. Text fields keep their own keys; only
// Escape leaves them. No DOM access, so node tests load it directly.
(function (root) {
  "use strict";

  const SINGLE = {
    j: "down", ArrowDown: "down", k: "up", ArrowUp: "up", g: "top", G: "bottom",
    Enter: "open", l: "open", ArrowRight: "open", Escape: "back", h: "back", ArrowLeft: "back",
    Tab: "focus", "/": "filter", r: "refresh", R: "refresh-all", y: "copy", o: "console",
    n: "next-error", N: "previous-error", a: "add", e: "edit", J: "move-down", K: "move-up",
    "?": "help", ":": "command", s: "save", ",": "settings",
  };

  function createKeyMap({ now = () => Date.now(), sequenceMs = 600 } = {}) {
    let firstD = null;
    return {
      action(event) {
        if (event.typing) return event.key === "Escape" ? "back" : null;
        if ((event.metaKey || event.ctrlKey) && !event.altKey && String(event.key).toLowerCase() === "k") return "command";
        if (event.metaKey || event.ctrlKey || event.altKey) return null;
        if (event.key === "d") {
          const at = now();
          if (firstD !== null && at - firstD <= sequenceMs) { firstD = null; return "remove"; }
          firstD = at;
          return null;
        }
        firstD = null;
        return Object.hasOwn(SINGLE, event.key) ? SINGLE[event.key] : null;
      },
    };
  }

  const HELP = [
    ["j k", "Move"], ["g G", "Top or bottom"], ["Enter", "Open"], ["Esc", "Back"], ["Tab", "List or inspector"],
    ["/", "Filter"], ["r", "Refresh"], ["R", "Refresh all"], ["y", "Copy"], ["o", "Open in AWS console"],
    ["n N", "Next or previous error"], ["a", "Add a thing"], ["e", "Edit"], ["dd", "Remove"], ["J K", "Move row"],
    [":", "Command line"], ["s", "Save result"], [",", "Settings"], ["?", "All keys"],
  ];

  root.CloudBurritoKeys = { createKeyMap, HELP };
})(typeof window !== "undefined" ? window : globalThis);
```

```js
// Inspector: a stack of views for one thing, shown with a breadcrumb trail.
// Kind-specific views register through register(); others use a generic view.
(function () {
  "use strict";
  const FACTORIES = {};
  function register(kind, factory) { FACTORIES[kind] = factory; }

  function create({ host, core, things: T, notice }) {
    const { el, clear } = core;
    let thing = null;
    let stack = [];
    const crumb = el("nav", { class: "wl-crumb", "aria-label": "Inspector path" });
    const account = el("span", { class: "wl-acct" });
    const body = el("div", { class: "wl-view", tabindex: "-1" });
    host.append(el("div", { class: "wl-inspector-head" }, crumb, account), body);
    const top = () => stack[stack.length - 1] || null;
    const helpers = { core, T, el, notice, push: view => push(view) };

    function genericView(t) {
      return { title: T.name(t), async render(view) {
        const { widget, inputs } = T.rowRequest(t);
        await core.fetchWidgetInto(view.host, widget, inputs, t.context);
      } };
    }
    function items(view) {
      const list = view?.items ? view.items(view.host) : [];
      list.forEach(node => { if (node.tabIndex < 0 && !node.hasAttribute("tabindex")) node.tabIndex = -1; });
      return list;
    }
    function highlight(view) {
      items(view).forEach((node, n) => {
        node.classList.toggle("wl-current", n === view.index);
        node.setAttribute("aria-current", String(n === view.index));
      });
    }
    function paint() {
      const view = top();
      clear(crumb);
      stack.forEach((v, n) => {
        if (n) crumb.append(el("span", { "aria-hidden": "true" }, "›"));
        crumb.append(el(n === stack.length - 1 ? "strong" : "span", {}, v.title));
      });
      account.textContent = thing ? `${thing.context.profile}, ${thing.context.region}` : "";
      account.title = thing ? `${thing.context.profile}, account ${thing.context.account_id}, ${thing.context.region}` : "";
      if (!view) { body.replaceChildren(el("p", { class: "wl-hint" }, "Select a thing and press Enter.")); return; }
      body.replaceChildren(view.host);
      if (!view.done) {
        Promise.resolve(view.render(view)).then(() => {
          if (view.host.isConnected) { view.done = true; highlight(view); }
        });
      } else highlight(view);
    }
    function push(view) {
      view.host = el("div", { class: "wl-view-host", "data-result-title": view.title });
      view.host._widgetContextOverride = thing.context;
      view.index = view.index || 0;
      view.done = false;
      stack.push(view);
      paint();
    }
    function show(t) {
      for (const v of stack) core.invalidateRequests(v.host);
      thing = t;
      stack = [];
      push((FACTORIES[t.kind] || genericView)(t, helpers));
    }
    function back() {
      if (stack.length <= 1) return false;
      core.invalidateRequests(stack.pop().host);
      paint();
      return true;
    }
    function move(delta) {
      const view = top();
      const list = items(view);
      if (!list.length) return;
      view.index = Math.max(0, Math.min(list.length - 1, (view.index || 0) + delta));
      highlight(view);
      list[view.index].focus({ preventScroll: true });
      list[view.index].scrollIntoView({ block: "nearest" });
    }
    function drill() { const view = top(); if (view?.open) view.open(view.index || 0, helpers); }
    function refresh() {
      const view = top();
      if (!view) return;
      core.invalidateRequests(view.host);
      clear(view.host);
      view.done = false;
      paint();
    }
    function copyMain() { const view = top(); return view?.copy ? view.copy(view.index || 0) : null; }
    function openConsole() {
      const view = top();
      const link = view?.consoleLink ? view.consoleLink(view.index || 0) : null;
      if (link) link.click(); else notice("No AWS console link is available here.");
    }
    function jumpError(delta) {
      const view = top();
      const lines = Array.from(view?.host.querySelectorAll(".log-line") || []);
      const errors = lines.map((line, n) => line.classList.contains("error") ? n : -1).filter(n => n >= 0);
      if (!errors.length) { notice("No error lines here."); return; }
      const current = view.index || 0;
      const next = delta > 0 ? errors.find(n => n > current) ?? errors[0] : [...errors].reverse().find(n => n < current) ?? errors[errors.length - 1];
      view.index = next;
      lines.forEach((line, n) => line.classList.toggle("wl-current", n === next));
      lines[next].scrollIntoView({ block: "center" });
    }
    function clearAll() {
      for (const v of stack) core.invalidateRequests(v.host);
      thing = null;
      stack = [];
      paint();
    }
    function focus() { const view = top(); const list = items(view); (list[view?.index || 0] || body).focus({ preventScroll: true }); }
    paint();
    return { show, back, move, drill, refresh, copyMain, openConsole, jumpError, clear: clearAll, focus,
      current: () => thing ? { thing, depth: stack.length } : null };
  }

  window.CloudBurritoInspector = { create, register };
})();
```

```js
// Cloud Burrito watchlist: specific things from many accounts, loaded when the
// user looks. Every request is pinned to its thing's own profile, account and
// region; there is no inherited account on this page.
(function () {
  "use strict";
  const core = window.CloudBurritoCore;
  const T = window.CloudBurritoThings;
  const { $, el, clear } = core;
  const keymap = window.CloudBurritoKeys.createKeyMap();
  const SIGN_IN_TYPES = ["CredentialsError", "CredentialsExpired", "IdentityVerificationFailed"];

  const state = {
    things: [], profiles: [], profilesKnown: false, allowedRegions: ["eu-west-1", "us-east-1"], settings: null,
    selectedId: null, filter: "", focus: "list", help: false, rows: new Map(), loadedAt: null, saveSeq: 0, storageReady: false,
  };

  let inspector = null;
  let noticeTimer = null;

  core.configure({
    contextFor: owner => core.contextOverrideFromElement(owner) || { mode: "inherit", profile: null, account_id: null, region: null },
    isIndependent: () => true,
    requestsAllowed: () => state.storageReady,
    resultTitle: host => host.closest?.("[data-result-title]")?.dataset.resultTitle || "Result",
    browserInvoke: !core.isTauri && window.CloudBurritoDemo ? window.CloudBurritoDemo.invoke : null,
  });

  const call = (command, params) => core.invoke(command, params ? { params } : undefined);

  function notice(message) {
    const box = $("#wl-notice");
    box.textContent = message;
    box.hidden = false;
    clearTimeout(noticeTimer);
    noticeTimer = setTimeout(() => { box.hidden = true; }, 6000);
  }

  function age(at) {
    const seconds = Math.max(0, Math.round((Date.now() - at) / 1000));
    if (seconds < 60) return "now";
    const minutes = Math.round(seconds / 60);
    if (minutes < 60) return `${minutes}m`;
    const hours = Math.round(minutes / 60);
    return hours < 48 ? `${hours}h` : `${Math.round(hours / 24)}d`;
  }

  function accountProblem(thing) {
    if (!state.profilesKnown) return null;
    const profile = state.profiles.find(p => p.name === thing.context.profile);
    if (!profile) return "profile is not in your AWS config";
    if (profile.account_id !== thing.context.account_id) return "profile now points to another account";
    return null;
  }

  const rowEl = id => id ? document.querySelector(`#wl-list .wl-row[data-thing-id="${CSS.escape(id)}"]`) : null;
  const selectedThing = () => state.things.find(t => t.id === state.selectedId) || null;
  const visibleRows = () => Array.from(document.querySelectorAll("#wl-list .wl-row:not([hidden])"));

  function buildRow(thing) {
    const kind = T.KINDS[thing.kind];
    const owner = el("div", { class: "wl-row-owner", hidden: true });
    const detailOwner = el("div", { class: "wl-row-owner-detail", hidden: true });
    owner._widgetContextOverride = thing.context;
    detailOwner._widgetContextOverride = thing.context;
    const row = el("li", { class: "wl-row", role: "option", tabindex: "-1", "aria-selected": "false", "data-thing-id": thing.id },
      el("span", { class: `wl-kind wl-kind-${thing.kind}`, title: kind.title, "aria-hidden": "true" }, kind.badge),
      el("span", { class: "wl-row-name", title: T.name(thing) }, T.name(thing)),
      el("span", { class: "wl-acct", title: `${thing.context.profile}, account ${thing.context.account_id}, ${thing.context.region}` }, thing.context.profile),
      el("span", { class: "wl-row-state", "data-tone": "muted" }),
      owner, detailOwner);
    row._thing = thing;
    row.addEventListener("click", () => { select(thing.id); openSelected(); });
    return row;
  }

  function emptyState() {
    return el("div", { class: "wl-empty" },
      el("h2", {}, "Add your first thing"),
      el("p", {}, "Press a to add a pipeline, package, log group or stack from any of your accounts."),
      el("button", { type: "button", class: "btn", onclick: () => actions.add?.() }, "Add a thing"));
  }

  function renderList() {
    const host = $("#wl-list");
    const existing = new Map(Array.from(host.querySelectorAll(".wl-row")).map(node => [node.dataset.thingId, node]));
    const fragment = document.createDocumentFragment();
    if (!state.things.length) fragment.appendChild(emptyState());
    for (const group of T.groupThings(state.things)) {
      const list = el("ul", { class: "wl-rows", role: "listbox", "aria-label": group.label });
      for (const thing of group.things) {
        const node = existing.get(thing.id);
        // Keep a row (and its in-flight load) when only the order changed.
        const same = node && JSON.stringify([node._thing.kind, node._thing.context, node._thing.inputs])
          === JSON.stringify([thing.kind, thing.context, thing.inputs]);
        if (same) { node._thing = thing; existing.delete(thing.id); }

      }
      fragment.append(el("h2", { class: "wl-group", "data-group": group.key }, group.label, el("span", {}, String(group.things.length))), list);

    select(state.selectedId && rowEl(state.selectedId) ? state.selectedId : visibleRows()[0]?.dataset.thingId || null, { focus: false });

  function applyFilter(text) {
    state.filter = text;
    const query = text.trim().toLowerCase();
    for (const node of document.querySelectorAll("#wl-list .wl-row")) {
      const t = node._thing;
      node.hidden = !!query && !`${T.name(t)} ${t.context.profile} ${T.KINDS[t.kind].title}`.toLowerCase().includes(query);
    }
    for (const heading of document.querySelectorAll("#wl-list .wl-group")) {
      const list = heading.nextElementSibling;
      heading.hidden = list.hidden = !list.querySelector(".wl-row:not([hidden])");

    if (state.selectedId && rowEl(state.selectedId)?.hidden) select(visibleRows()[0]?.dataset.thingId || null, { focus: false });
  }

  function renderSummary() {
    const accounts = new Set(state.things.map(t => `${t.context.profile}|${t.context.account_id}`)).size;
    const count = state.things.length;
    const loaded = state.loadedAt ? `, loaded ${new Intl.DateTimeFormat("en-GB", { hour: "2-digit", minute: "2-digit" }).format(state.loadedAt)}` : "";
    $("#wl-summary").textContent = count ? `${count} thing${count === 1 ? "" : "s"} in ${accounts} account${accounts === 1 ? "" : "s"}${loaded}` : "";
  }

  function paintRow(thing) {
    const row = rowEl(thing.id);
    if (!row) return;
    const info = state.rows.get(thing.id) || {};
    const cell = row.querySelector(".wl-row-state");
    clear(cell);
    cell.dataset.tone = info.tone || info.summary?.tone || "muted";
    cell.append(el("span", { class: "wl-state-text" }, info.label ?? info.summary?.text ?? ""));

    else if (info.partial) cell.append(el("span", { class: "wl-state-flag" }, "partial"));

    if (at && !info.label) cell.append(el("time", { class: "wl-age", datetime: new Date(at).toISOString() }, age(at)));
  }

  function setRow(thing, info) {
    state.rows.set(thing.id, info);
    paintRow(thing);
  }

  async function enrichPackage(thing, row, list) {
    const rows = Array.isArray(list?.rows) ? list.rows : [];
    const exact = rows.find(r => r.package === thing.inputs.package_prefix);
    const targets = (exact ? [exact] : rows).filter(r => r.enrichment_state !== "complete").slice(0, 5).map(r => r.package);
    if (!targets.length || core.resultFailure(list)) return list;
    const owner = row.querySelector(".wl-row-owner-detail");
    const request = core.beginOwnedRequest(owner, thing.context);
    const i = thing.inputs;
    const enriched = await core.fetchWidgetData("codeartifact-packages", { mode: "enrich", domain: i.domain, repository: i.repository,
      package_prefix: i.package_prefix, ...(i.domain_owner ? { domain_owner: i.domain_owner } : {}), packages: targets },
      owner, thing.context, request);
    if (!request.accept(enriched)) return null;
    const byName = new Map((Array.isArray(enriched.rows) ? enriched.rows : []).map(r => [r.package, r]));
    return { ...list, rows: rows.map(r => byName.get(r.package) || r), ...(core.resultFailure(enriched) ? { partial: true } : {}) };
  }

  function applyRowResult(thing, result) {
    const previous = state.rows.get(thing.id) || {};
    const outcome = core.resultState(result);
    if (outcome === "denied") return setRow(thing, { label: `blocked by policy: ${result.action || "request"}`, tone: "fail" });
    if (SIGN_IN_TYPES.includes(result?.error_type) || result?.needs_sso_login === true || outcome === "expired") {
      return setRow(thing, { label: "sign in needed", tone: "warn", copy: `aws sso login --profile ${thing.context.profile}` });
    }
    if (outcome === "failed" || outcome === "cancelled") {
      const message = outcome === "cancelled" ? "cancelled" : "failed, press r to retry";
      if (previous.summary && !previous.label) return setRow(thing, { ...previous, stale: true, error: message });
      return setRow(thing, { label: message, tone: outcome === "cancelled" ? "muted" : "fail" });
    }
    setRow(thing, { summary: T.summarize(thing, result), partial: outcome === "partial" || outcome === "limited", receivedAt: Date.now(),
      copy: thing.kind === "package" ? T.summarize(thing, result).text : null });
  }

  function applyRowFailure(thing, message) {
    const previous = state.rows.get(thing.id) || {};
    if (previous.summary && !previous.label) return setRow(thing, { ...previous, stale: true, error: message });
    setRow(thing, { label: "failed, press r to retry", tone: "fail" });
  }

  async function loadRow(thing, { run = false } = {}) {
    const row = rowEl(thing.id);
    if (!row) return;
    const problem = accountProblem(thing);
    if (problem) return setRow(thing, { label: `needs account: ${problem}`, tone: "warn" });
    const previous = state.rows.get(thing.id) || {};
    if (!T.KINDS[thing.kind].autoload && !run) {
      return setRow(thing, previous.summary ? previous : { label: "not run yet", tone: "muted" });
    }
    const owner = row.querySelector(".wl-row-owner");
    const request = core.beginOwnedRequest(owner, thing.context);
    row.dataset.loading = "true";
    if (!previous.summary) setRow(thing, { label: "loading", tone: "muted" });
    try {
      const { widget, inputs } = T.rowRequest(thing);
      let result = await core.fetchWidgetData(widget, inputs, owner, thing.context, request);
      if (!request.accept(result)) return;
      if (thing.kind === "package") result = await enrichPackage(thing, row, result);
      if (result) applyRowResult(thing, result);
    } catch (error) {
      if (request.current()) applyRowFailure(thing, String(error?.message || error));
    } finally {
      row.dataset.loading = "false";
    }
  }

  function refreshAll() {
    state.loadedAt = Date.now();
    renderSummary();
    for (const group of T.groupThings(state.things)) for (const thing of group.things) loadRow(thing);
  }

  async function save() {
    const seq = ++state.saveSeq;
    try {
      const result = await call("watchlist_set", { things: T.toStored(state.things) });
      if (seq === state.saveSeq && result?._storage?.status !== "saved") throw new Error("not saved");
    } catch (_) {
      if (seq === state.saveSeq) notice("Changes could not be saved. The file on disk was not changed. Try again.");
    }
  }

  function select(id, { focus = true } = {}) {
    state.selectedId = id;
    for (const node of document.querySelectorAll("#wl-list .wl-row")) {
      const on = node.dataset.thingId === id;
      node.setAttribute("aria-selected", String(on));

  function moveSelection(to) {

    if (!rows.length) return;

  function setFocus(area) {

    if (!thing) return;

  }

  function moveThing(delta) {
    const thing = selectedThing();
    if (!thing) return;
    state.things = T.move(state.things, thing.id, delta);
    renderList();
    rowEl(thing.id)?.focus();
    save();
  }

  const KEYBAR = {
    list: [["j k", "Move"], ["Enter", "Open"], ["/", "Filter"], ["r", "Refresh"], ["R", "Refresh all"], ["a", "Add"], ["e", "Edit"], ["dd", "Remove"], ["?", "All keys"]],
    inspector: [["j k", "Move"], ["Enter", "Open"], ["Esc", "Back"], ["y", "Copy"], ["o", "Console"], ["n", "Next error"], ["r", "Refresh"], ["?", "All keys"]],
  };
  function renderKeys() {
    const host = $("#wl-keys");
    clear(host);
    for (const [keys, label] of (state.help ? window.CloudBurritoKeys.HELP : KEYBAR[state.focus])) {
      host.append(el("span", { class: "wl-key" }, ...keys.split(" ").map(k => el("kbd", {}, k)), label));
    }
  }

  Object.assign(actions, {
    down: () => state.focus === "list" ? moveSelection(1) : inspector.move(1),
    up: () => state.focus === "list" ? moveSelection(-1) : inspector.move(-1),
    top: () => state.focus === "list" ? moveSelection("top") : inspector.move(-1000),
    bottom: () => state.focus === "list" ? moveSelection("bottom") : inspector.move(1000),
    open: () => state.focus === "list" ? openSelected() : inspector.drill(),
    back: () => {
      const filter = $("#wl-filter");
      if (document.activeElement === filter) { filter.value = ""; applyFilter(""); setFocus("list"); return; }
      if (state.help) { state.help = false; renderKeys(); return; }
      if (state.focus === "inspector" && !inspector.back()) setFocus("list");
    },
    focus: () => setFocus(state.focus === "list" ? "inspector" : "list"),
    filter: () => $("#wl-filter").focus(),
    refresh: () => {
      const thing = selectedThing();
      if (!thing) return;
      loadRow(thing, { run: true });
      if (inspector.current()?.thing.id === thing.id) inspector.refresh();

    "refresh-all": () => refreshAll(),
    copy: () => copyMain(),
    console: () => inspector.openConsole(),
    "next-error": () => inspector.jumpError(1),
    "previous-error": () => inspector.jumpError(-1),
    remove: () => removeSelected(),
    "move-down": () => moveThing(1),
    "move-up": () => moveThing(-1),
    help: () => { state.help = !state.help; renderKeys(); },
  });

  document.addEventListener("keydown", event => {
    if (event.defaultPrevented || document.querySelector("dialog[open]")) return;
    const target = event.target;
    const typing = target instanceof HTMLElement && (target.isContentEditable || ["INPUT", "TEXTAREA", "SELECT"].includes(target.tagName));
    const action = keymap.action({ key: event.key, metaKey: event.metaKey, ctrlKey: event.ctrlKey,

    if (["open", "focus"].includes(action) && !typing && !onSurface) return;

  async function boot() {
    $("#wl-mode").hidden = core.isTauri;

    $("#wl-list").addEventListener("focusin", () => { if (state.focus !== "list") { state.focus = "list"; document.body.dataset.focus = "list"; renderKeys(); } });

    try {
      const settings = await call("settings_get");

    } catch (_) { notice("Settings could not be loaded. Defaults are used."); }

      const info = await call("aws_list_profiles");

        .filter(p => p.eligibility === "supported_sso" && p.name && p.account_id)
```

```js
// Pure parser and completion for the ":" command line. No DOM or bridge.
// Every thing command resolves one pinned profile, account and region.
(function (root) {
  "use strict";
  const THING_COMMANDS = { pipe: "pipeline", pkg: "package", logs: "logs", stack: "stack", stacks: "stacks-search",
    lookup: "lookup", errors: "errors", insights: "query", aws: "cli" };
  const APP_COMMANDS = ["add", "settings", "policy", "audit", "theme", "help", "classic"];
  const RANGES = { "15m": 900, "1h": 3600, "3h": 10800, "12h": 43200, "24h": 86400, "3d": 259200, "7d": 604800 };
  const MISSING = {
    pipeline: "Add a pipeline name, for example :pipe payments-api.",
    package: "Add a package name and its domain/repository.",
    logs: "Add a Lambda function name, or a log group that starts with /.",
    stack: "Add a stack name.",
    "stacks-search": "This stack search could not be read.",
    lookup: "Add a resource name, ARN or partial ID.",
    errors: "This error count could not be read.",
    query: "Add a log group and a quoted query, for example :insights /aws/lambda/fn \"fields @message | limit 20\".",
    cli: "Write a full command after :aws, for example :aws sts get-caller-identity.",
  };
  const HELP = [
    [":pipe <name> @profile", "Pipeline runs"],
    [":pkg <name> <domain>/<repository> @profile", "Package versions"],
    [":logs <function or /log/group> @profile", "Log streams and events"],
    [":stack <name> @profile", "Stack resources and events"],
    [":stacks [prefix] @profile", "Search stacks"],
    [":lookup <text> @profile", "Find tagged resources"],
    [":errors [pattern] [hours] @profile", "Error counts, runs Logs Insights and can cost money"],
    [":insights <log group> \"<query>\" [1h] @profile", "Logs Insights query, can cost money"],
    [":aws <command> @profile", "Reviewed read-only AWS CLI command"],
    [":add  :settings  :policy  :audit  :theme  :help", "App commands"],
  ];

  function tokenize(text) {
    const tokens = [];
    let current = "", quote = null, started = false;
    for (const ch of text) {
      if (quote) { if (ch === quote) quote = null; else current += ch; continue; }
      if (ch === '"' || ch === "'") { quote = ch; started = true; continue; }
      if (/\s/.test(ch)) { if (started) { tokens.push(current); current = ""; started = false; } continue; }
      current += ch;
      started = true;
    }
    if (quote) return null;
    if (started) tokens.push(current);
    return tokens;
  }
  const requote = token => /[\s"']/.test(token) ? (token.includes('"') ? `'${token}'` : `"${token}"`) : token;

  function parse(input, env) {
    const text = String(input || "").replace(/^:/, "").trim();
    if (!text) return { ok: false, error: "Type a command, for example pipe payments-api @prod-core." };
    if (text.length > 16384 || /[\u0000-\u001f\u007f]/u.test(text)) return { ok: false, error: "The command is too long or contains control characters." };
    const name = text.split(/\s+/)[0].toLowerCase();
    if (APP_COMMANDS.includes(name)) return { ok: true, type: "app", name };
    const kind = THING_COMMANDS[name];
    if (!kind) return { ok: false, error: `Unknown command ${name}. Type :help to see all commands.` };
    const tokens = tokenize(text.slice(name.length).trim());
    if (!tokens) return { ok: false, error: "A quote is not closed." };
    let profileName = null, region = null;
    const kept = [];
    for (const token of tokens) {
      if (token.length > 1 && token.startsWith("@")) { profileName = token.slice(1); continue; }
      if (kind !== "cli" && (env.allowedRegions || []).includes(token)) { region = token; continue; }
      kept.push(token);
    }
    profileName = profileName || env.defaultProfile || null;
    if (!profileName) return { ok: false, error: "Add @profile, for example @prod-core." };
    const profile = (env.profiles || []).find(p => p.name === profileName);
    if (!profile) return { ok: false, error: `Unknown profile @${profileName}. Type @ and press Tab to see your profiles.` };
    region = region || ((env.allowedRegions || []).includes(profile.region) ? profile.region : env.defaultRegion);
    if (!region) return { ok: false, error: "Add a supported region, for example eu-west-1." };
    const context = { mode: "pinned", profile: profile.name, account_id: profile.account_id, region };
    let raw;
    switch (kind) {
      case "pipeline": raw = { pipeline_name: kept.join(" ") }; break;
      case "package": {
        const [pkg, repo] = kept;
        let domain = "", repository = "";
        if (repo && repo.includes("/")) [domain, repository] = repo.split("/", 2);
        else { const known = (env.packageRepos || []).find(r => r.profile === profile.name); if (known) ({ domain, repository } = known); }
        if (!pkg || !domain || !repository) return { ok: false, error: pkg ? "Add the repository as domain/repository, for example acme/pypi-internal." : MISSING.package };
        raw = { package_prefix: pkg, domain, repository };
        break;
      }
      case "logs": {
        const target = kept.join(" ");
        raw = target.startsWith("/") ? { source: "group", log_group: target }
          : { source: "lambda", function_name: target, log_group: target ? `/aws/lambda/${target}` : "" };
        break;
      }
      case "stack": raw = { stack_name: kept.join(" ") }; break;
      case "stacks-search": raw = { name_prefix: kept.join(" ") }; break;
      case "lookup": raw = { query: kept.join(" ") }; break;
      case "errors": {
        const hours = kept.find(t => /^\d+$/.test(t));
        raw = { log_group_pattern: kept.find(t => !/^\d+$/.test(t)) || "/aws/lambda/", hours: hours ? Number(hours) : 24 };
        break;
      }
      case "query": {
        const [group, query, range] = kept;
        if (range && !RANGES[range]) return { ok: false, error: "Use a range of 15m, 1h, 3h, 12h, 24h, 3d or 7d." };
        raw = { log_group: group, query, range_seconds: RANGES[range] || 3600 };
        break;
      }
      case "cli": raw = { command: kept.length ? `aws ${kept.map(requote).join(" ")}` : "" }; break;
    }
    const inputs = root.CloudBurritoThings.inputsFor(kind, raw);
    return inputs ? { ok: true, type: "thing", kind, context, inputs } : { ok: false, error: MISSING[kind] };
  }

  function complete(input, env) {
    const text = String(input || "");
    const word = (text.match(/(\S*)$/) || ["", ""])[1];
    const from = text.length - word.length;
    const head = text.replace(/^:/, "").trimStart();
    let items;
    if (word.startsWith("@")) {
      items = (env.profiles || []).filter(p => p.name.startsWith(word.slice(1)))
        .map(p => ({ value: `@${p.name}`, label: `@${p.name}`, detail: p.account_id }));
    } else if (!/\s/.test(head)) {
      const prefix = word.startsWith(":") ? ":" : "";
      items = [...Object.keys(THING_COMMANDS), ...APP_COMMANDS].filter(c => c.startsWith(word.replace(/^:/, "")))
        .map(c => ({ value: `${prefix}${c} `, label: c, detail: "" }));
    } else {
      const names = (env.names || {})[THING_COMMANDS[head.split(/\s+/)[0].toLowerCase()]] || [];
      items = names.filter(n => n.startsWith(word)).map(n => ({ value: n, label: n, detail: "" }));
    }
    return { from, to: text.length, items: items.slice(0, 8) };
  }

  root.CloudBurritoCommands = { parse, complete, tokenize, HELP, THING_COMMANDS, APP_COMMANDS, RANGES };
})(typeof window !== "undefined" ? window : globalThis);
```

```js
// The ":" command line: parse, complete, run as an unsaved thing in the
// inspector, and save with s. Commands never run hidden work.
(function () {
  "use strict";
  const W = window.CloudBurritoWatchlist;
  const core = window.CloudBurritoCore;
  const T = window.CloudBurritoThings;
  const C = window.CloudBurritoCommands;
  const { el } = core;
  let bar, input, list, hint, suggestions = [], active = 0;

  function env() {
    const things = W.state.things;
    const names = kind => [...new Set(things.filter(t => t.kind === kind).map(t => T.name(t)))];
    return {
      profiles: W.state.profiles, defaultProfile: W.state.settings?.default_profile || "",
      defaultRegion: W.state.settings?.default_region || "", allowedRegions: W.state.allowedRegions,
      packageRepos: things.filter(t => t.kind === "package").map(t => ({ profile: t.context.profile, domain: t.inputs.domain, repository: t.inputs.repository })),
      names: { pipeline: names("pipeline"), stack: names("stack"), package: names("package") },
    };
  }

  function renderSuggestions() {
    const text = input.value;
    suggestions = text.trim() ? C.complete(text, env()).items
      : C.HELP.map(([usage, detail]) => ({ value: null, label: usage, detail }));
    active = Math.min(active, Math.max(0, suggestions.length - 1));
    list.replaceChildren(...suggestions.map((item, n) => el("li", { role: "option", id: `wl-command-option-${n}`,
      "aria-selected": String(n === active) }, el("span", {}, item.label), el("span", { class: "wl-muted" }, item.detail || ""))));
    list.hidden = !suggestions.length;
    input.setAttribute("aria-expanded", String(!list.hidden));
    if (suggestions.length) input.setAttribute("aria-activedescendant", `wl-command-option-${active}`);
    else input.removeAttribute("aria-activedescendant");
  }

  function applySuggestion() {
    const item = suggestions[active];
    if (!item?.value) return;
    const { from, to } = C.complete(input.value, env());
    input.value = input.value.slice(0, from) + item.value + input.value.slice(to);
    active = 0;
    renderSuggestions();
  }

  function open(text = "") {
    bar.hidden = false;
    input.value = text;
    hint.textContent = "";
    active = 0;
    renderSuggestions();
    input.focus();
  }

  function close() {
    bar.hidden = true;
    list.hidden = true;
    W.setFocus(W.state.focus);
  }

  function run() {
    const result = C.parse(input.value, env());
    if (!result.ok) { hint.textContent = result.error; return; }
    close();
    if (result.type === "app") {
      if (result.name === "help") { open(""); return; }
      const handler = W.appCommands[result.name];
      if (handler) handler(); else W.notice(`:${result.name} is not available on this page.`);
      return;
    }
    const thing = { id: `unsaved-${Date.now().toString(36)}`, kind: result.kind, context: result.context,
      inputs: result.inputs, order: 0, unsaved: true };
    W.inspector.show(thing);
    W.setFocus("inspector");
    const kind = T.KINDS[thing.kind];
    W.notice(kind.cost ? "Not saved. This command can cost money. Press r to run it, or s to save it."
      : kind.autoload ? "Not saved. Press s to save it to your watchlist." : "Not saved. Press r to run it, or s to save it.");
  }

  function saveShown() {
    const shown = W.inspector.current()?.thing;
    if (!shown?.unsaved) { W.notice("Only command results can be saved with s."); return; }
    const thing = T.create(shown.kind, shown.context, shown.inputs, W.state.things);
    W.state.things = [...W.state.things, thing];
    W.renderList();
    W.select(thing.id, { focus: false });
    W.loadRow(thing);
    W.inspector.show(thing);
    W.save();
    W.notice(`Saved ${T.name(thing)} to your watchlist.`);
  }

  function mount() {
    input = el("input", { id: "wl-command-input", type: "text", role: "combobox", "aria-label": "Command",
      "aria-controls": "wl-command-list", "aria-expanded": "false", "aria-autocomplete": "list", autocomplete: "off", spellcheck: "false" });
    list = el("ul", { id: "wl-command-list", class: "wl-command-list", role: "listbox", "aria-label": "Suggestions", hidden: true });
    hint = el("p", { id: "wl-command-hint", class: "wl-command-hint", role: "status" });
    bar = el("div", { id: "wl-command", class: "wl-command", hidden: true },
      el("span", { class: "wl-command-prompt", "aria-hidden": "true" }, ":"), input, hint, list);
    document.getElementById("wl-keys").before(bar);
    input.addEventListener("input", () => { hint.textContent = ""; active = 0; renderSuggestions(); });
    input.addEventListener("keydown", event => {
      if (event.key === "Enter") { event.preventDefault(); run(); }
      else if (event.key === "Escape") { event.preventDefault(); close(); }
      else if (event.key === "Tab") { event.preventDefault(); applySuggestion(); }
      else if (event.key === "ArrowDown" || event.key === "ArrowUp") {
        event.preventDefault();
        if (!suggestions.length) return;
        active = (active + (event.key === "ArrowDown" ? 1 : -1) + suggestions.length) % suggestions.length;
        renderSuggestions();
      }
    });
    W.actions.command = () => open("");
    W.actions.save = () => saveShown();
  }

  if (document.readyState === "loading") document.addEventListener("DOMContentLoaded", mount, { once: true });
  else mount();
})();
```

```js
  function migrateTiles(tiles, env = {}) {
    const things = [];
    const seen = new Set();
    let converted = 0, skippedNoAccount = 0, skippedEmpty = 0;
    const profileContext = name => {
      const p = (env.profiles || []).find(x => x.name === name);
      if (!p) return null;
      const region = (env.allowedRegions || []).includes(p.region) ? p.region : env.defaultRegion;
      return region ? { mode: "pinned", profile: p.name, account_id: p.account_id, region } : null;
    };
    const add = (kind, context, inputs) => {
      const probe = normalize({ id: "probe", kind, context, inputs, order: 0 });
      if (!probe) return false;
      const key = JSON.stringify([kind, probe.context, probe.inputs]);
      if (!seen.has(key)) { seen.add(key); things.push(create(kind, probe.context, probe.inputs, things)); }
      return true;
    };
    for (const tile of Array.isArray(tiles) ? tiles : []) {
      if (!tile || typeof tile !== "object") continue;
      const widget = String(tile.widget || String(tile.id || "").split(":")[0]);
      const config = tile.config && typeof tile.config === "object" ? tile.config : {};
      const inputs = config.inputs && typeof config.inputs === "object" ? config.inputs : {};
      const raw = config.context || config.account_override;
      const own = raw && (raw.mode === "pinned" || !raw.mode && raw.profile) ? pinned({ ...raw, mode: "pinned" }) : null;
      const tileContext = own || (env.defaultProfile ? profileContext(env.defaultProfile) : null);
      let made = 0, needsAccount = false;
      const want = (kind, context, values) => {
        if (!context) { needsAccount = true; return; }
        if (add(kind, context, values)) made++;
      };
      const pins = key => Array.isArray(inputs[key]) ? inputs[key] : [];
      switch (widget) {
        case "pipeline-runs": pins("pinned_pipelines").forEach(pin => want("pipeline", pinned({ ...pin, mode: "pinned" }), { pipeline_name: pin.pipeline_name })); break;
        case "aws-cli":
          pins("pinned_cli_commands").forEach(pin => want("cli", pinned({ ...pin, mode: "pinned" }), { command: pin.command }));
          if (inputs.command) want("cli", tileContext, { command: inputs.command });
          break;
        case "codeartifact-packages": if (inputs.domain && inputs.repository && inputs.package_prefix) want("package", tileContext, inputs); break;
        case "logs-insights": if (inputs.log_group && inputs.query) want("query", tileContext, inputs); break;
        case "errors-by-stack": want("errors", tileContext, inputs); break;
        case "cfn-stacks": if (inputs.name_prefix || Array.isArray(inputs.status_filter) && inputs.status_filter.length) want("stacks-search", tileContext, inputs); break;
        case "resource-lookup": if (inputs.query) want("lookup", tileContext, inputs); break;
        case "log-tail": case "cloudwatch-logs":
          if (inputs.log_group) want("logs", tileContext, { log_group: inputs.log_group, source: widget === "log-tail" ? "lambda" : "group" });
          break;
        default: break;
      }
      if (made) converted++; else if (needsAccount) skippedNoAccount++; else skippedEmpty++;
    }
    return { things, converted, skippedNoAccount, skippedEmpty };
  }
```

```rust
/// Status for one pinned thing. Uses the same verification and cache as its
/// widget requests, reads only local SSO cache metadata, and never touches the
/// top-bar connection state.
async fn aws_auth_status_pinned(
    state: &AppState,
    params: &Value,
    request: &mut RequestEnvelope,
) -> Result<Value, String> {
    let scope = &params["context"];
    let mut out = json!({
        "has_context": false, "logged_in": false, "profile": scope["profile"].clone(),
        "account_id": scope["account_id"].clone(), "region": scope["region"].clone(),
        "sso_session": Value::Null, "caller_arn": Value::Null, "needs_sso_login": false,
        "expires_at": Value::Null, "sso_token_expires_at": Value::Null,
        "read_only_guard_active": true, "error": Value::Null, "connection_state": "unverified",
    });
    let resolved = match resolve_widget_ctx(state, params) {
        Ok(resolved) => resolved,
        Err(error) => {
            out["error"] = error["error"].clone();
            out["error_type"] = error["error_type"].clone();
            return Ok(out);
        }
    };
    let policy = aws::policy::load(&state.runtime.paths).map_err(|e| e.message);
    let session = match verify_request_context_owned(state, &resolved, &policy, Some(request)).await {
        Ok(session) => session,
        Err(error) => {
            out["error"] = error.get("error").or_else(|| error.get("reason")).cloned().unwrap_or(Value::Null);
            out["error_type"] = error.get("error_type").cloned().unwrap_or(Value::Null);
            out["needs_sso_login"] = json!(out["error"].as_str().is_some_and(aws::sso_login_required));
            out["connection_state"] = json!("failed");
            return Ok(out);
        }
    };
    let backend = state.runtime.aws.clone();
    let snapshot = session.snapshot.clone();
    let sso_token_expiry = tokio::time::timeout(
        std::time::Duration::from_secs(2),
        tokio::task::spawn_blocking(move || backend.sso_token_expiry(&snapshot)),
    )
    .await
    .ok()
    .and_then(Result::ok)
    .flatten();
    if let Err(error) = validate_request_context(state, &resolved, &session) {
        out["error_type"] = error["error_type"].clone();
        out["error"] = error["error"].clone();
        return Ok(out);
    }
    request.bind(&resolved.context, &session);
    let format = aws_smithy_types::date_time::Format::DateTime;
    out["has_context"] = json!(true);
    out["logged_in"] = json!(true);
    out["connection_state"] = json!("verified");
    out["account_id"] = json!(session.identity.account_id);
    out["sso_session"] = json!(session.snapshot.session_name);
    out["caller_arn"] = json!(session.identity.arn);
```

```js
        .flatMap(color => ["--wl-bg", "--wl-panel"].map(surface => ({ color, surface, value: ratio(color, surface) })));
    }, theme);
```
